# Freesia design tokens — 2026-09-30 approved brand direction
User/team preference supersedes previous Nebius-inspired visual shell. Original Freesia botanical theme with sidebar navigation.
## Brand and layout
Freesia mark: small asymmetric yellow trumpet blossoms on a curved green stem, SVG, text brand remains the accessible link name. Native Segoe UI/system font; no download.
White outer background, ivory/cream panels, botanical green primary controls and dark green text, amber flower highlights. No purple gradient, charcoal cloud-console imitation, or added font/icon dependencies.
Left sidebar with the Freesia flower brand and three independent destinations: Infrastructure, Applications, Integrations. The top header keeps project, demo role and data source controls. On mobile the menu expands below the header in normal reading order; selecting a destination closes it. No horizontal page overflow.
## Product meaning
Infra admin: create Space -> guided infrastructure questions/Terraform -> explicit infrastructure demo deployment. Application admin sees Infra read-only and chooses an enterprise/target Space, not a network template. Integrations connects GitHub and registers repositories in advance; application creation/deployment selects only registered repositories and never includes URL entry. Deploy triggers analysis -> 2-3 eligible compute choices with mascot/branching tree -> Terraform/repository preview -> simulated commit/push/CI/CD -> result. Generated code alone never makes a foundation ready. App detail retains Overview/Logs/Monitoring tabs. Integrations is a main destination, not a third Space.
Demo/API indicator visible. Errors, unsupported API and sample data explicit. Preserve drafts/session guards/SSE cleanup/resume and native keyboard affordances. Minimum text contrast4.5:1, UI controls3:1 where applicable; focus visible. Keep number/status labels understandable without color.

## Applied palette and typography
Canvas #ffffff, paper #fffdf7, ink #253a31, muted #59685c, primary #326448, active Space #234e36, amber #f0c74e. Brand name uses locally installed Georgia serif; Korean UI remains Segoe UI/system. Editable input/select boundary #81917b separates controls from cream surfaces; decorative panel separators remain #d8ddce.
