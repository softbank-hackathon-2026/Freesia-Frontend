# Freesia design tokens — 2026-09-30 approved brand direction
User/team preference supersedes previous Nebius-inspired visual shell. Original Freesia botanical theme with sidebar navigation.
## Brand and layout
Freesia brand icon: user-provided house mascot reused from public/freesia-mascot.jpg. Original flower mark is preserved as public/freesia-flower.svg; text brand remains the accessible link name. Native Segoe UI/system font; no download.
White outer background, ivory/cream panels, botanical green primary controls and dark green text, amber flower highlights. No purple gradient, charcoal cloud-console imitation, or added font/icon dependencies.
Left sidebar with the Freesia house mascot brand and three independent destinations: Infrastructure, Applications, Integrations. The top header keeps the project and data source control. The demo role selector and role notice are removed so reviewers can inspect the entire flow without switching personas. On mobile the menu expands below the header in normal reading order; selecting a destination closes it. No horizontal page overflow.
## Product meaning
Review mode: all infrastructure and application demo actions are accessible without role switching. Infrastructure Space creation and AI-guided design remain separate data flows; saved designs are not automatically wired to Space deployment. App creation chooses an enterprise/target Space, not a network template. Infra creation remains unavailable in API mode until supported by the backend. Integrations connects GitHub and registers repositories in advance; application creation/deployment selects only registered repositories and never includes URL entry. Deploy triggers analysis -> 2-3 eligible compute choices with mascot/branching tree -> Terraform/repository preview -> simulated commit/push/CI/CD -> result. Generated code alone never makes a foundation ready. App detail retains Overview/Logs/Monitoring tabs. Integrations is a main destination, not a third Space.
Demo/API indicator visible. Errors, unsupported API and sample data explicit. Preserve drafts/session guards/SSE cleanup/resume and native keyboard affordances. Minimum text contrast4.5:1, UI controls3:1 where applicable; focus visible. Keep number/status labels understandable without color.

## Applied palette and typography
Canvas #ffffff, paper #fffdf7, ink #182d23, muted #43564b, primary #17633f, active Space #123f2b, amber #f0c74e. Brand name uses locally installed Georgia serif; Korean UI remains Segoe UI/system. Editable input/select boundary #718474 separates controls from cream surfaces; decorative panel separators use #b6c3b8.

## Contrast update — 2026-10-01
Reference principles: [Supabase color usage](https://supabase.com/design-system/docs/color-usage) separates dashboard canvas, surfaces and functional accents; [Vercel Geist colors](https://vercel.com/geist/colors) distinguishes background, borders and high-contrast foreground. Freesia keeps its own ivory/green brand. Sidebar #e9efe8, canvas/header white, panel headings #f0f4ec and table headings #e8eee5. Selected tabs and primary controls use dark green with white text. Demo/API sample banners use #b42318 with white text; limitation notices and errors use #fff1f0 with #9b1c1c and a red boundary. No dependency or business-flow changes.
